# Baztit Tech

Custom automation for growing businesses. Landing page and solutions catalog.

## Setup

```bash
npm install
npm start
```

Server runs on `http://localhost:3000` (or `PORT` from environment).

## Structure

- `/public` — static assets (HTML, CSS, JS)
- `server.js` — Express server for Railway deployment

## Deployment

Deploy to [Railway](https://railway.app). Set `PORT` via environment (auto-set by Railway).
